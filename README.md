# Simple Login Interface

A static login form created to practice HTML form markup and CSS styling.

## Features

Username and password inputs, associated labels, a submit button and decorative styling.

## Technology

HTML, CSS and Google Fonts.

## Getting started

```sh
git clone https://github.com/mefrinthearea/simple_login.git
cd simple_login
```

Open `login/index.html` in a browser. No package installation or build step is required. External fonts or icons may require an internet connection.

## Entry point

`login/index.html`

## Scope and limitations

No authentication, server or credential storage is implemented. Use dummy values only.

## Project status

Early learning project retained to document development progress. Source reviewed for documentation; runtime behavior has not been re-tested in this update.
